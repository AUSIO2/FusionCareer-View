# 岗位批量导入接口约定

前端直接使用后端提供的模板和导入接口，不维护模板副本。

## 下载模板

- `GET /admin/job-post/import-template`
- 返回后端当前支持的 `.xlsx` 模板。
- 前端使用带 `Fusion-Token` 的下载请求，避免静态模板与解析规则漂移。

## 导入岗位

- `POST /admin/job-post/import`
- 请求类型：`multipart/form-data`
- 文件字段：`file`
- 前端接受 `.xlsx`、`.xls`，最大 10 MB；后端请求上限为 20 MB。
- 后端会先校验整个工作簿；任一数据行不合法时整次导入失败，不会部分保存。
- 校验通过后，所有岗位以 `PUBLISHED` 状态批量保存并立即上线。

成功响应沿用统一的 `R<T>`，其中 `data` 是发布岗位数：

```json
{
  "code": 200,
  "message": "成功导入 3 条岗位",
  "data": 3
}
```

前端不得把成功结果描述为“进入草稿箱”。如果产品需要先进入草稿箱，应先修改后端导入状态和接口文档，再同步调整页面。
